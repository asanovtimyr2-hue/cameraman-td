# Conquer Europe WW2

Пошаговая стратегия: экономика, исследования, дипломатия, фронты, морские десанты и ядерная программа. Играется в браузере, один файл — `index.html`.

## Как играть
1. Откройте `conquer-europe-procrastinate/index.html`
2. Выберите страну (у каждой свой флаг, промышленность и сложность)
3. Ход → «Следующий ход». Побег из нейтралитета: оправдание войны (3 хода) → объявление войны → наступления по суше или десанты (нужен флот и порт)

## Механики
- Экономика: гражданские заводы (финансы, исследования), военные заводы (сила наступления), инфраструктура
- Ресурсы: финансы, живая сила, сталь, нефть
- 6 технологий: пехота, промышленность, танки, авиация (тратит нефть), флот (открывает десанты), ракеты (ядерная программа)
- Дипломатия: оправдание войны, белое перемирие после 12 ходов
- ИИ: 5 держав развиваются, захватывают малые страны и объявляют войну игроку
- Победа: контроль 80% Европы. Поражение: потеря всех территорий

## Технически
Один самодостаточный HTML-файл, без зависимостей. Флаги отрисованы как SVG.

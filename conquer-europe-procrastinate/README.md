# Conquer Europe WW2: Procrastinate

Пародия на Roblox-плейс «Conquer Europe WW2» (в 2026 — «Conquer The World WW2»).
Отдельная игра в своей папке — основной index.html репозитория (cameraman-td) не затронут.

## Как играть
Открой `conquer-europe-procrastinate/index.html` в браузере (или на GitHub Pages).

## Что внутри
- Выбор страны: Люксембург/Швейцария советует гайд, Ватикан — сверхдержава (400 танков)
- Justification = пост в Discord, 24 лайка; Five Checks перед войной
- Гражданские заводы раньше военных; последнюю монету не тратить
- Морские десанты с шансом «Порт не на том берегу»
- Промокоды через корзину слева: LUXEMBOURG_NEUTRAL:| , VATICAN-MEGA:D (и пасхалка SPAIN_GOOD)
- 6 бейджей, голосование за эру после партии (сервер всё равно выберет WW3)
